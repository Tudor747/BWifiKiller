# BWifiKill ESP32 V4.0 binaries

This folder contains the release binaries.

These are the original prebuilt binaries and do not include the English source translations. Rebuild the local project with PlatformIO for the English interface.

| File | Usage |
| --- | --- |
| `BWifiKill-ESP32-V4.0-full.bin` | Full binary for Web Flasher or `esptool.py` at offset `0x0`. |
| `firmware.bin` | Main application generated by PlatformIO. |
| `bootloader.bin` | Bootloader generated by PlatformIO. |
| `partitions.bin` | Partition table used by the build. |
| `boot_app0.bin` | Auxiliary Arduino ESP32 framework image included in the full binary. |

Recommended manual flashing:

```bash
esptool.py --chip esp32 --baud 921600 write_flash 0x0 binarios/BWifiKill-ESP32-V4.0-full.bin
```
